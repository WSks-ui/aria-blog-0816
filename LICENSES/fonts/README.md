# 字体许可

本目录记录项目自托管字体的许可文件和来源

- `Space Grotesk`：Fontsource `5.3.0`，字体文件来自Space Grotesk项目，使用SIL Open Font License 1.1
- `Source Serif 4`：Fontsource `5.3.0`，字体文件来自Google Fonts，使用SIL Open Font License 1.1
- `JetBrains Mono`：Fontsource `5.3.0`，字体文件来自JetBrains Mono项目，使用SIL Open Font License 1.1

页面只复制了Latin或Latin-ext子集，中文字符继续使用项目原有的Noto Serif SC分片
