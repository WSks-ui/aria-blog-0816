最近重新系统地看了一遍Linux，想起来之前虽然学习过Linux，但是没有过记录的笔记。所以想记录一下，不过是偏个人博客形式的

## Linux主要用在哪里

### 企业服务器

企业后台通常更看重稳定性、可自动化程度和资源利用率。Linux的开放生态、权限模型、远程管理能力和脚本工具，适合长期运行Web服务、数据库、DNS、邮件、代理和容器等基础设施

企业服务器并非只使用Linux。在互联网和基础设施场景中，Linux通常是必须理解的一套工作环境。很多服务不需要图形界面，管理员通过SSH登录后，就可以完成部署、配置、监控和故障排查

### 嵌入式设备

Linux内核可以适配多种处理器和硬件设备，因此也广泛出现在路由器、交换机、智能终端、车载设备和各种物联网产品中。嵌入式系统往往需要在有限资源下保持稳定运行，这正是Linux生态擅长的方向之一

### 个人设备

在传统桌面电脑上，Windows和macOS仍然更常见；但Android等移动系统、智能电视和大量网络设备，都建立在Linux内核或Linux生态之上。换句话说，平时看不见Linux桌面的地方，Linux依然可能参与其中

## Linux对学习和就业意味着什么

Linux是一条和多种能力相连的知识线。真正使用它时，通常会同时接触到：

- Shell和日常命令行操作
- 操作系统中的进程、文件、内存和设备管理
- 计算机网络与服务器部署
- C语言、系统调用和系统编程
- 自动化脚本、日志分析和问题定位
- 阅读文档、搜索资料与验证解决方案

这些能力会继续分化成运维、后端开发、数据库管理、网络服务、嵌入式开发和系统编程等方向。因此，Linux更像技术职业中的底层训练场：它未必直接决定你做什么，却会影响你能不能看懂运行环境、定位问题并把服务真正跑起来

## 第一次连接Linux环境

最容易开始的方式，是准备一台云服务器或虚拟机，再通过SSH客户端连接。Windows上可以使用Xshell、Windows Terminal或其他SSH工具；连接时需要准备主机地址、端口、用户名和密码或密钥

连接成功后，可以用一个很小的C程序完成第一次练习：

```bash
touch test.c
vim test.c
```

写入代码：

```c
#include <stdio.h>

int main(void) {
	printf("Hello, Linux!\n");
	return 0;
}
```

保存退出后编译并运行：

```bash
gcc test.c
./a.out
```

这个过程同时练习了文件创建、终端编辑、编译器调用、相对路径和可执行文件运行。它比单纯背命令更容易建立整体感

## 我的理解

学习Linux的重点在于逐渐熟悉用户命令、Shell、操作系统和硬件之间的关系。遇到问题时，知道应该查什么、在哪里查、如何验证结果，往往比记住某一条命令更重要
