这节课没急着讲命令，先聊了一个问题：人是怎么跟计算机打交道的

## 指令和界面都是交互方式

早期的计算机只有键盘，能做的就是敲指令。后来有了鼠标、显示器和图形系统，才有了现在点来点去的图形界面

两者要做的事其实一样，都是告诉操作系统"我要干什么"，只是方式不同：

| 方式 | 好处 | 不方便的地方 |
| --- | --- | --- |
| 图形界面 | 直观，上手快 | 批量操作、远程管理、自动化都麻烦 |
| 命令行 | 精确，能组合，能写成脚本 | 要记命令，敲错了可能后果很严重 |

学命令行不是要扔掉图形界面，多一种用法而已

## 操作系统在中间干什么

大概是这么一层层叠起来的：

```text
用户程序、图形界面、Shell
            |
操作系统内核
  进程 / 文件 / 内存 / 设备管理
            |
驱动程序
            |
硬件设备
```

普通程序不能直接去碰硬件。驱动把具体设备包一层，内核管进程、文件、内存和设备，再往上给出接口。我们用的图形界面、Shell、各种软件，都是调这些接口干活

## 服务器上为什么还得用命令行

自己的电脑一直用图形界面没问题，服务器就不一样了：

1. 服务器一般不装桌面，省资源，要维护的东西也少
2. SSH连上去，面前就只有一个终端
3. 一串命令可以存成脚本，下次直接跑，也方便别人检查
4. 看日志、进程、网络、权限，敲命令往往比点界面快

## 先从路径和文件操作开始

Linux的文件系统从根目录`/`开始。`.`是当前目录，`..`是上一级，`~`是当前用户的家目录。记住这几个，下面的命令就好懂了：

```bash
pwd                 # 查看当前目录
ls -la              # 查看目录内容，包括隐藏文件
cd ..               # 返回上一级目录
cd /var/log         # 使用绝对路径进入目录
cd -                # 回到上一次所在的目录
touch note.txt      # 创建空文件
mkdir -p demo/src   # 创建多级目录
rmdir empty-dir     # 删除空目录
rm -i note.txt      # 删除前询问确认
```

以`/`开头的是绝对路径，在哪执行都指向同一个地方；相对路径要看当前在哪，写脚本时容易在这上面出错

`rm -r`会把目录连同里面的东西一起删掉，而且没有回收站。我现在的习惯是删之前先`pwd`、`ls`看一眼自己在哪
