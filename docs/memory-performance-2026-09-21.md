# 内存检查与背景缓冲优化

## 测量范围

通过 Playwright 驱动 Edge，使用生产构建产物测试 `/types/note/` 与长文
`/posts/linux-command-time-search-compression/` 的 12 轮往返。每个采样点等待
3.5 秒再主动 GC，通过 CDP 记录 JS 堆、DOM 节点和监听器。另测连续天气切换与缩放。
该测试不等同于浏览器任务管理器中的整个标签页驻留内存，也不包含准确的 GPU 进程分摊。

首轮加载文章模块后，节点数稳定为 1740、监听器稳定为 390，后续第 4、8、12 轮
没有增长。优化前第 1 轮 JS 堆约 2.17 MiB，第 12 轮约 2.61 MiB；优化后约 2.18
与 2.61 MiB。此次未确认持续的节点/监听器泄漏，也没有宣称 JS 堆显著下降。
浏览器内部堆仍有增长，12 轮短测不足以排除所有长期问题。

## 调整

- WebGL 上传临时二维画布后，使用 `finally` 将宽高归零，立即弃用画布像素存储。
  纹理上传已取得像素副本，不依赖该临时画布继续存活。窗口缩放/天气切换后的
  采样中，仍可访问的临时画布像素容量从 19.8 MiB 降至 0。
  这是宽 × 高 × 4 的容量估算，实际物理内存归还时机仍由浏览器与驱动决定。
- 背景绘制缓冲新增 4,194,304 像素预算，DPR 仍最多为 2；着色器、纹理光栅化和
  纤维平铺共用实际绘制比例。单张 RGBA 缓冲约不超过 16 MiB，浏览器可能维护多张。
- 保留原有天气效果和 24fps 动画。仅装饰背景在大视口下可能降采样，文字、内容图片、
  封面、标题共享转场不受此预算影响。

桌面、移动端及大视口分别验证晴天、雨天、夜间：截图可见、中心区域非黑，
WebGL 错误码为 0，缩放后继续正常绘制。`pnpm build` 生成 77 页；
`pnpm check` 为 0 errors / 0 warnings，保留两个原有 hints。

阅读流程回归覆盖桌面雨天/夜间、移动端晴天/reduced-motion、原生转场 fallback、
历史导航、阅读保存与快速退出。首次并发运行时 fallback 的“继续阅读”可见性断言
失败一次；停止其它测试后完整重跑全部通过。尚未定位这次波动的根因，不据此宣称
已解决该间歇性问题，也没有为通过测试修改阅读逻辑。

## 首页专项补充

在 1440 × 900、DPR 2 下，首页还维护了一张 2554 × 1220 的雨幕画布，
单张 RGBA 像素容量约 11.9 MiB。原逻辑滚出首屏只停止 RAF，画布仍保持原尺寸；
`SVG.pauseAnimations()` 只控制 SVG 时间线，不能暂停组件实际使用的 CSS 动画。

本次调整：

- Hero 雨幕使用独立的 2,097,152 像素预算；实测为 2095 × 1000，约 8 MiB。
- 滚出首屏或切到后台归零雨幕尺寸；重新可见时恢复缓冲和绘制。离场时也主动归零。
- 绝对定位 Hero 装饰层离屏时使用 `content-visibility: hidden`，并显式暂停 CSS 动画。
  它不承担布局高度，不使用整节内容的估算占位。
- 首页固定大小的离屏 SVG 封面跳过绘制。最近记录单独观察原件和循环副本，避免克隆
  初始化标记后无人更新可见性；观察器随舞台实例清理。
- 首页揭幕清理函数执行后清空自身模块引用，避免该闭包继续持有旧 `page`。
  此项属于代码中确认的引用清理，当前 DOM 总量对照没有显示可独立归因的下降。

首页 JS 堆主动 GC 后约 1.35 MiB，并非本次观察到的主要占用。额外使用浏览器 CDP
进程 ID 对照 Windows 工作集，发现图形进程明显更大：本机无头 Edge 的正常首页
单轮工作集约 805 MiB，加入离屏封面跳过绘制后另一轮约 697 MiB。禁用 Hero 或
封面的诊断样本也有较大波动，不能将单轮差值归为稳定优化比例；GPU 进程工作集
也不是独占显存或某个用户标签页的准确分摊。多层 SVG、滤镜、背景混合仍有成本。

验证覆盖桌面、移动端、reduced-motion；雨幕非空像素及运动变化、离屏归零、滚回
恢复、页面总高度不变、循环原件/副本可见、首页与关于页往返、页面脚本错误、截图。
构建与类型检查通过。LayerTree 在本机无头模式没有返回有效图层，未以其零值推断
图层内存为零。首页往返的 DOM/内部堆采样尚不能排除所有保留引用，不宣称全面消除泄漏。

本机脚本和数据：`.visual-check/navigation/home-memory.mjs`、`home-visual.mjs`、
`home-process.mjs` 及同名前缀 JSON/截图。
