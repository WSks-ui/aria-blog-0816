# 图形实验室

独立入口：`/ta/`。博客主导航的「实验室」与页脚的「图形实验室」进入此页。

## 设计边界

- 共用 Aria-7 品牌和自托管字体，使用独立文档、深色样式与全幅实时场景。
- 不加载博客天气、雨声、光标、路由动画。Three.js 只在实验室动态加载。
- 不展示当前课程、学历与学习进度，不使用成长口号或解释性占位段落。
- 项目和笔记仅在存在已发布的 `lab` 内容时显示；导航与首屏入口同步出现。
- 不混排主博客技术文章，不提供“全部文章”或主博客 RSS 入口，只保留明确的返回博客链接。
- 首屏背景为 AI 辅助实现的俯视等高线实时重建（参考 MUSYNX RETURN 的 `Dark_2D` 画面，未使用其素材），不作为作者独立完成的作品或性能成绩。

## 维护内容

`src/data/ta.ts` 仅维护内容分类。没有内容时隐藏整个栏目，不显示“尚未发布”等占位说明。
联系区域仅保留标题、邮件和 GitHub；参考来源与 AI 辅助说明保留在实验参数面板中。

TA 项目和笔记继续放在 `src/content/posts/`。保留原有文章 frontmatter，在其中增加：

```yaml
lab:
  type: project
  discipline: graphics
  status: in-progress
```

- `type`：`project`（项目）或 `note`（学习记录）。
- `discipline`：`graphics`（图形学）、`rendering`（实时渲染）、`tools`（工具与管线）。
- `status`：`in-progress`（进行中）或 `complete`（已完成），由作者按实际状态填写。
- `draft: true` 的文章不会进入实验室。
- 不填写 `lab` 的文章不会自动成为 TA 内容，即使原来的 `kind` 是 `project`。
- 项目封面用文章现有的 `cover`；没封面时展示文字，不制造虚假截图。
- 两个以上项目方向存在时才出现筛选按钮；禁用 JavaScript 时直接显示全部真实项目。
- 当前 TA 首页在呈现上独立筛选内容；存储仍复用 `posts` 集合，
  项目与笔记详情仍复用博客文章页。本次未引入独立内容集合或详情路由。

项目文章建议写清问题、个人完成部分、实现方法、对比结果、尚存问题与源码。
引用课程框架、外部素材或 AI 辅助部分时在文章中说明，不把学习复现写成原创引擎。

## 首屏背景

整页背景是实时俯视等高线地图，由 `src/lib/topography-scene.ts` 与 `src/components/ta/TopographyBackdrop.astro`
驱动，使用自己定义的地形、单位编排与标注，未复制游戏视频、截图、贴图或着色器代码。
细节与边界见 `docs/topography-lab.md`。

原水下透光实验（`src/components/ta/OceanStudy.astro`、`src/lib/ocean-scene.ts`、`src/shaders/ocean*.glsl`）
保留在仓库中但不再挂到 TA 页面；它的参数与测试仍在 `scripts/ocean-settings.test.mjs`。

维护时运行：

```sh
pnpm test:lab
pnpm check
pnpm build
```

测试使用项目已有 TypeScript 编译器转译纯配置模块，不依赖浏览器或额外测试运行时。

`public/assets/ta/topography-poster.webp` 与 `topography-mobile.webp` 是整页背景加载前和渲染不可用时的画面，
`topography-og.webp` 是 1200×630 分享图，均从 `/ta/topography/` 的实际画布导出。
调整着色器或编排后应重新导出，并检查导出不是空白；不要拿带页面文字的截图作后备图。

### 原水下透光实验（未挂载）

以下为原水下实验的记录，仅在重新挂载时适用。

五个视图使用同一个场景：成片、水面、法线、透光和泛光。
所有档位最高 30 FPS，脏标记不绕过帧间隔；这是调度上限，不是实测性能承诺。
自动档像素预算分别为 55、110、207.36 万，法线噪声分别为 7、8、10 层，DPR 最大 1.5。
手动高画质固定内部缓冲为 1920×1080，不受视口和 DPR 影响；
射线按画布显示比例补偿，非 16:9 和手机画面不会被拉伸。
最终 sRGB 合成结果经 Three.js FXAA 后输出，不重复进行色彩转换。
自动档连续两组超预算才降档，不自动升档。离屏或后台停止调度。
减少动态偏好下默认静止，仍可手动播放。上下文丢失、无 HDR 支持或无 JS 时显示静态图。

`public/assets/ta/submerged-poster.webp` 和 `submerged-mobile.webp` 分别是桌面、手机
实际 GPU 场景导出的画面；`submerged-og.webp` 是 1200×630 分享图。三张图仍在仓库中，当前页面不再引用。

独立页不启用 Astro ClientRouter；博客入口带 `data-astro-reload`，
避免跨布局继承天气状态或持久化监听器。返回博客恢复其原有本地主题设置。

## 原水下实验视觉维护（未挂载）

- 固定机位，桌面俯仰 0.72 弧度、竖屏 0.42 弧度；视野随纵横比连续过渡。
  鼠标仅产生小幅偏转；时间只推进波面，不再移动相机。
- 高度场采用截图中的 `0.6` 空间缩放、旋转倍频矩阵、`0.3` 初始权重、
  `0.45` 权重衰减和 `1.3` 时间频率增长。高度带为 `[0.5, 0.5 + 0.546 * wave]`，
  求交共享六层低频波形，法线最多十层，并根据像素足迹衰减高频。
- 四面体差分使用截图中的四个方向。透光采用 `refract(ray, normal, 1.333)`、
  `sun = normalize(vec3(0, -1, 9))`、`exp(dot(ref, sun) * 9 - 9)` 与 `sqrt(spec) * fog`。
  移除了之前独立的窄光核和额外菲涅耳乘数，不使用黑色噪声遮挡。
- 泛光尺寸为 1/2、1/4、1/8、1/16，分尺度权重为 0.12、0.22、0.30、0.36。
  第一层采用软阈值，其余层逐级降采样并做 64 点 Fibonacci 旋转核模糊；
  核权重为 `1/(1+i)`，固定单位起点，半径分别为各层的 3、6、12、16 像素。
  节能档用第三层复用最粗光晕。
- 场景、泛光先在线性 HDR 中相加，再曝光和转换输出。不要重新添加 OutputPass，
  不要在 renderer 上重复启用色调映射。“泛光”分层直接显示光晕纹理。
- 调整时先看“透光”，再看“成片”；大波轮廓与近远变化必须在关闭泛光时成立。

### 参考公式与适配边界

上述公式来自用户提供的拆解截图，不等于已取得或完整验证 XorDev 原作源码。
截图缺少 `value()`、相机原点、步进边界、完整中间缓冲以及输出色彩空间。
这些缺失部分采用本站实现：三次插值值噪声、有界求交、响应式相机和统一 sRGB 输出。
最终 HDR 的 `18 * vec3(light^4, light^5, light^6)` 是明确的艺术性通道响应，
不是截图原公式，也不是物理吸收模型。“透光”视图显示未经过该暖色响应的灰度信号。
泛光使用截图的旋转核与权重，但保持网站的四级分辨率预算，没有宣称复刻完整缓冲链。

开发环境可固定时刻进行截图，生产包会移除这些事件监听：

```js
const canvas = document.querySelector('[data-ocean-canvas]');
canvas.dispatchEvent(new CustomEvent('ocean:seek', { detail: 12 }));
// 待 data-scene-time 等于 12.000 后截图；同样检查 24、36 秒。
canvas.addEventListener('ocean:captured', (event) => {
  // event.detail 为无页面文字的 WebP data URL。
  console.log(event.detail);
}, { once: true });
canvas.dispatchEvent(new Event('ocean:capture'));
```

导出发生在绘制后、默认帧缓冲清空前，不常驻开启 `preserveDrawingBuffer`。
先确认画布状态为 `live` 且在视口内，再触发导出。
